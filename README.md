# Cloud-Init NoCloud Seed Generator

[中文版](./README.zh.md)

A professional web-based tool designed to create `NoCloud` configuration ISO images for virtual machine environments like Hyper-V and VMware.

## 🚀 Features

- **Professional Web GUI**: Modern, interactive interface built with React and TailwindCSS.
- **Multilingual Support**: Automatically detects browser language (English/Chinese) and supports manual switching.
- **User Management**: 
  - Advanced **Root** user control (Password, SSH keys, SSH password login toggle).
  - Regular user creation with sudo privileges and SSH keys.
- **SSH Configuration**: Robust support for SSH password authentication across various distributions, including forced overrides for Ubuntu 24.04+ and AlmaLinux 9+.
- **Regional Settings**: Cascading timezone selection (Region > City).
- **Network Configuration**: Supports both DHCP v4 and Static IPv4 (Address, Gateway, DNS).
- **Instance ID Generation**: Quick UUID v4 generator for unique instance identification.
- **Wide OS Support**: Compatible with Ubuntu 22.04+, RHEL/AlmaLinux/Rocky Linux 8+, and other NoCloud compatible environments.
- **Dockerized**: Single-container deployment with multi-stage builds.

## 🛠️ Getting Started

### Prerequisites

- [Docker](https://docs.docker.com/get-docker/)
- [Docker Compose](https://docs.docker.com/compose/install/)

### Run with Docker Compose

Simply run the following command in the project root:

```bash
docker-compose up --build
```

The application will be accessible at: **[http://localhost:8000](http://localhost:8000)**

## 📦 Project Structure

- `backend/`: FastAPI backend for YAML and ISO generation.
- `frontend/`: React frontend with i18n support.
- `Dockerfile`: Multi-stage build for the combined application.
- `docker-compose.yml`: Orchestration for the single-container service.
